# 콩콩 수학 놀이터

유아가 **수 개념(몇 개, 몇 마리, 비교하기)** 을 익힐 수 있도록 만든 웹 게임입니다.

## 기능
- **개수 세기 모드**: 사물/동물 이모지를 보고 몇 개인지 맞히기
- **비교 모드**: 두 그룹 중 더 많은 쪽 고르기
- **난이도 3단계**: 쉬움(1~5), 보통(1~9), 어려움(1~12)
- 정답/오답 피드백, 연속 정답(스트릭) 표시
- 처음부터 다시 시작 버튼 제공

## 실행 방법
### 방법 1) 파일 바로 열기
1. `index.html` 파일을 브라우저에서 엽니다.

### 방법 2) 로컬 서버로 실행 (권장)
1. 터미널에서 프로젝트 폴더로 이동합니다.
2. 아래 명령으로 실행합니다.

```bash
./run_local.sh 8000
```

3. 브라우저에서 `http://localhost:8000` 접속

> 기본 포트는 `8000`이며, 다른 포트를 쓰고 싶으면 숫자를 바꿔 실행하면 됩니다.


## 이 환경에서 가능한 확인
- 이 실행 환경에서는 브라우저 화면을 직접 띄울 수 없을 수 있습니다.
- 대신 아래 스모크 테스트로 서버가 정상 동작하는지 확인할 수 있습니다.

```bash
./smoke_test.sh 8130
```

- `HTTP/1.0 200 OK` 와 `SMOKE_TEST=PASS` 가 나오면 정상입니다.
